# 账号安全与身份核验规范

## 适用范围

处理异常登录、忘记密码、验证码异常、账户冻结、陌生设备、访问令牌或 API Key 疑似泄露等问题。该 Skill 提供安全处置流程，不替代正式身份核验或安全事件调查。

## 首次响应要求

1. 先确认用户是否仍能控制绑定邮箱、手机号或已登录设备。
2. 明确提醒用户：不要发送密码、完整验证码、恢复码、API Key、Cookie 或身份证件原图。
3. 建议立即停止在可疑页面输入信息，并在官方入口修改密码或撤销会话。
4. 仅收集最小必要信息：问题发生时间、登录方式、脱敏账号标识、陌生设备或地点描述、错误码或截图（遮挡敏感内容）。

## 标准处置路径

### 异常登录或疑似账号被盗

- 引导用户在可信设备上修改密码，并确保新密码唯一、长度足够且不复用。
- 建议退出其他设备会话、检查近期登录记录、开启多因素认证。
- 若绑定方式已被更改、存在未授权操作或无法控制原绑定渠道，立即升级人工安全核验。

### 密码重置或验证码问题

- 核对用户使用的是官方重置入口、验证码是否在有效期内，以及设备时间与网络是否正常。
- 多次失败、账户锁定或验证码被异常消耗时，不猜测原因；收集脱敏错误信息后升级处理。
- 不提供绕过验证码、跳过验证或替代身份凭证的方案。

### Token 或 API Key 疑似泄露

- 建议用户立即在对应平台撤销或轮换凭证，检查最近调用与权限范围。
- 不要求用户在聊天中粘贴任何密钥，也不复述用户意外提供的密钥。
- 若凭证已造成异常调用、资金风险或数据访问风险，按安全事件升级并保留时间线。

## 升级条件与交接信息

满足以下任一条件时，标记为需人工安全处理：疑似盗号、身份无法核验、异常权限变更、密钥泄露、账户冻结影响关键业务或存在未授权交易。交接时记录时间线、受影响范围、已完成措施和脱敏证据；不要附带密码、验证码或密钥。

## 回复边界

- 不确认账户是否一定被盗，也不承诺固定解锁或恢复时长。
- 不披露其他账户、设备、日志或内部风控规则。
- 在信息不足时，优先给出止损步骤，再说明需要人工核验的原因与下一步。
